# Draggy GPS — Raspberry Pi 4

הפרויקט קורא נתוני מיקום ומהירות ממודול GPS מסוג L80-39, מחשב נתוני ביצועים
ושולח אותם בזמן אמת כ־JSON לטלפון ולמחשב באותה רשת מקומית. במקביל כל המדידות
נשמרות מקומית על ה־Raspberry Pi, כך שהמידע נשאר זמין גם אם אין לקוח מחובר.

אין בפרויקט HTML. הממשק הוא API קטן, כדי שאפשר יהיה לחבר אליו בהמשך אפליקציה,
Dashboard או תוכנת מחשב בלי לשנות את קוד איסוף ה־GPS.

## מה עובד עכשיו

- קריאת משפטי `$GPRMC` ו־`$GNRMC` מחיבור USB/UART.
- בדיקת NMEA checksum ודחיית מדידות ללא GPS fix.
- המרת מיקום לפורמט decimal degrees ומהירות מקשרים לקמ״ש.
- מהירות נוכחית ושיא מהירות.
- תאוצה נוכחית ושיא G חיובי.
- זמנים מיטביים של 0–20, 0–50, 0–100, 10–60 ו־100–200 קמ״ש.
- שמירה רציפה בקובץ JSON Lines מקומי.
- `GET /stats` לקבלת התוצאה האחרונה.
- `GET /events` לזרם SSE חי שמתעדכן עם כל מדידת GPS.

## חיבור החומרה

המוצר הוא מודול L80-39 וכולל ממיר CP2102 מ־USB ל־UART. הדרך הפשוטה ב־Pi 4 היא
לחבר אותו ב־USB. בדרך כלל הוא יופיע כ־`/dev/ttyUSB0`; אפשר לבדוק בעזרת:

```bash
ls -l /dev/ttyUSB*
```

המפרט מציין קצב ברירת מחדל של 1Hz ועד 5Hz. לתוצאות האצה מדויקות יותר כדאי
להגדיר בהמשך 5Hz במודול עצמו; הקוד מעבד כל משפט RMC שמתקבל ואינו תלוי בקצב קבוע.

## התקנה על Raspberry Pi OS

```bash
git clone https://github.com/uneftin/draggy.git
cd draggy
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 src/main.py --port /dev/ttyUSB0
```

אם המשתמש אינו מורשה לפתוח את החיבור הסריאלי:

```bash
sudo usermod -aG dialout "$USER"
```

אחרי הפקודה צריך להתנתק ולהתחבר מחדש.

## צפייה מהמחשב ומהטלפון

מוצאים את כתובת ה־IP של ה־Pi:

```bash
hostname -I
```

כאשר ה־Pi והטלפון/מחשב מחוברים לאותה רשת, פותחים:

```text
http://PI_IP:8765/stats
```

זו תמונת המצב האחרונה כ־JSON. לקוח שתומך ב־SSE יכול להתחבר לזרם החי:

```text
http://PI_IP:8765/events
```

השרת מאזין לרשת המקומית בלבד לפי הגדרת הרשת. אין בו אימות משתמשים, ולכן אין
לחשוף את פורט 8765 ישירות לאינטרנט.

## שמירת מדידות

ברירת המחדל היא `data/gps.jsonl`. כל שורה היא snapshot מלא אחרי מדידה אחת.
אפשר לבחור יעד אחר:

```bash
python3 src/main.py --log-file /home/pi/draggy-runs/run-01.jsonl
```

## סימולציה ללא GPS

```bash
python3 src/main.py --stdin
```

מדביקים משפטי NMEA תקינים, שורה בכל פעם. `quit` מסיים את הקלט.

## בדיקות

```bash
python3 -m unittest discover -s tests -v
```

הבדיקות מכסות checksum, פירוק RMC, המרת יחידות, חישובי ביצועים, שמירה לקובץ
ו־endpoint של הנתונים החיים.

## ההבדל בין Draft 1 ל־Draft 2

הגרסאות הישנות נשמרו בתיקיות `draft1` ו־`draft2` לצורך תיעוד:

- Draft 1 בודק ומפרק משפטי GPS, אך `calculate` עדיין ריק.
- Draft 2 מוסיף שיא מהירות, תאוצה, G וזמני האצה.
- Draft 2 גם בודק ששעת UTC מספרית ומטפל בחישוב תאוצה שחוצה חצות.
- בשניהם הקלט עדיין ידני, כל המדידות נשמרות ב־RAM ואין שידור חי.
- קובץ `src/main.py` הנוכחי הוא ההמשך עבור Raspberry Pi 4; אין צורך להריץ את
  קובצי ה־drafts.

## מגבלות נוכחיות

- זמן חציית סף מהירות מחושב לפי דגימות ה־GPS, בלי interpolation בין שתי דגימות.
- קפיצה רגעית במהירות יכולה להשפיע על התאוצה ועל שיא G; עדיין אין noise filter.
- הזרם החי הוא JSON ולא ממשק גרפי לטלפון.
- יש לבדוק על החומרה את שם הפורט וקצב ה־baud בפועל.
